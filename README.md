# 🎓 Computer Vision-Based Automated Attendance Tracking System
Bachelor's Thesis
## 📌 About the Project

The system automates student attendance tracking in educational institutions using facial recognition on group photos. The instructor takes a photo of the classroom via a mobile app; the server detects faces, compares them against a reference database, and returns a list of attendees. Results are stored in a database, with Excel reports and statistics available.

### Problem Addressed

- Traditional roll calls take **5–10 minutes** per class session.
- Paper-based registers are prone to errors and fraud (e.g., a student signing in for an absent peer).
- Commercial alternatives are expensive, require an internet connection, or are inaccessible to educational institutions.

### Solution

- The instructor takes **one group photo** — the system recognizes everyone present.
- Processing time: **2–5 seconds** on a CPU.
- Recognition accuracy: **95% (Accuracy)**, **94% (Recall)**.
- Operates **locally**, without transmitting biometric data to third parties.
